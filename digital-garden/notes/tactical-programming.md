Tactical programming is the local execution of a defined change: writing a function, adding an endpoint, modifying a query, creating a component, fixing a bug, or updating a test.

AI agents are increasingly capable of tactical programming. Tactical success does not guarantee strategic success: code may compile and tests may pass while the feature solves the wrong problem or damages the system's long-term structure.

Tactical work should operate inside a strategic system that provides a clear goal, explicit constraints, meaningful feedback, appropriate boundaries, and review.
